## Real Problems

1. 首轮 Typecheck：TS5108，TypeScript 7 移除旧 `moduleResolution=node10`；根因是把历史 `Node` resolution 当成稳定默认。最小修复先切现代 Node resolution。
2. 第二轮 Typecheck：TS1479，NestJS 12 是 ESM package，而应用仍被识别为 CommonJS。最终基线改为 `NodeNext + type=module + relative .js imports`，不引入兼容 hack。
3. 依赖安装期间 Registry 多个 GET 出现 `ECONNRESET`；pnpm 自恢复并完成安装，最终不是 blocker。
