## 关键纠偏

- Bounded Context 从旧版 Knowledge/Retrieval/Conversation/Evaluation/Platform 等拆法收敛为三个真正有独立语义与生命周期的 Context：Knowledge Management、Grounded Answering、Quality & Evaluation。
- Retrieval/Rerank/Context/Generation 保留为 Grounded Answering 内部的独立 Capability Spec，而不是伪装成业务领域。
- PostgreSQL、Model Gateway、Dev Tunnel、Site Delivery 明确为 Contract/Runtime/Adapter，不是 Domain。
- 新增冻结 `Context Map` 与 `Cross-Context Communication`，明确同步 Contract、Event、Port 三种允许通信方式，以及跨域直接 SQL/import 的禁止规则。
- 建立 Requirement ID 与 Acceptance Matrix，覆盖 PRD、SYS 和三个 Context 的硬不变量。
- Spec 状态采用分层冻结：上层治理/产品/系统/领域已冻结；Capability/Contract/Runtime/Verification 为 REVIEWED，等待实现/实测逐项冻结具体参数；ADR 为 ACCEPTED。
