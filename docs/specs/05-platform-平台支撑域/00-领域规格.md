# Platform｜平台支撑域规格

状态：FROZEN_V0_2026-09-03

## 1. 领域使命
Platform 负责让核心领域在真实 Mac + iPhone + 公网环境中稳定运行，包括 PostgreSQL、Model Gateway、配置、安全、Dev Tunnel、调度、健康检查和进程生命周期。它是支撑域，不拥有 RAG 业务语义。

## 2. 设计原则
核心领域依赖稳定 Port/Contract，不依赖 `192.168.x.x`、数据库连接字符串、launchd plist 或具体隧道命令。基础设施可以替换，领域对象与业务契约不应因此重写。

## 3. 运行资源
- Mac：NestJS Backend、PostgreSQL/pgvector、知识构建任务、Dev Tunnel 客户端。
- iPhone：Embedding、Reranker、Qwen 3.6 4B FAST/THINK 等模型推理服务。
- GitHub：`proflow-rag` 与 ProFlow 源码权威远端。
- ChatGPT Sites：Delivery hosting，不承担数据库与模型算力。

## 4. 隔离原则
数据库、Backend port、Tunnel identity、日志、配置均使用 ProFlow RAG 独立命名空间。禁止 `killall node`、`pkill node` 等会伤及 gptweb-mcp 或其他项目的广域进程命令。

## 5. 不变量
数据库与手机模型不直接暴露公网；所有手机请求经 Model Gateway；public health 不泄露内部拓扑/secret；开发期不强制 launchd；稳定后 launchd 只调用仓库自己的生命周期脚本。

## 6. 验收
任一基础设施故障都有明确 health/error；模型离线不会拖死无限请求；数据库重启后服务可恢复；Dev Tunnel 只映射目标服务；ProFlow RAG 生命周期不改动 gptweb-mcp 既有管理方式。
