# V0 范围与非目标

状态：FROZEN_V0_2026-09-03

## In Scope

- 单一公开 ProFlow Corpus；来源只认 GitHub `main`。
- 文档、真实源码、测试进入语料；敏感/生成/缓存/依赖产物过滤。
- 全量 Snapshot rebuild + 验证 + 原子激活 + 上一版回滚。
- Doc / Code / Test 结构感知 Chunk，固定长度 Chunk 仅作 Eval baseline。
- PostgreSQL FTS/精确文本能力 + pgvector Hybrid Search。
- RRF + 独立 Reranker。
- Evidence/Context、FAST/THINK、SSE、Source Citation。
- 匿名 Conversation、Trace、👍/👎、RAG Eval。
- Mac 原生 PostgreSQL、Dev Tunnel、iPhone LAN 模型服务。

## Non-goals

- 通用知识库 SaaS、任意用户上传文档。
- 用户账号、团队 Workspace、计费。
- 多仓库、多分支、多历史版本选择。
- 微服务、Kafka、Elasticsearch、独立向量数据库。
- Docker 作为本地运行前提。
- ORM。
- OpenAI Responses API 作为公网主链。
- MCP 作为 V0 Site 主入口。
- 用 LangChain/LlamaIndex 黑盒替代核心 RAG 学习链。
