# ProFlow RAG｜产品总规格

状态：FROZEN_V0_2026-09-03

## 1. 产品定位

ProFlow RAG 是一个公开、真实、可审计的工程型 RAG 产品，用于让外部用户理解 ProFlow 的定位、架构、源码、测试和开发事实，同时展示完整 RAG 工程能力。未来同一知识能力可以接入 ProFlow 自身迭代流程，但 V0 优先公开 Site。

## 2. 核心需求

- `PRD-001`：用户无需登录即可询问 ProFlow。
- `PRD-002`：回答必须基于公开 ProFlow `main` 的可追溯证据。
- `PRD-003`：回答必须流式展示，不能等待整段完成。
- `PRD-004`：每个事实型回答必须展示不可变 GitHub Source。
- `PRD-005`：系统必须同时处理自然语言与 CLI、路径、symbol、错误串等精确工程词。
- `PRD-006`：默认 FAST，复杂问题才进入 THINK。
- `PRD-007`：用户可使用极简 👍 / 👎 反馈。
- `PRD-008`：每次真实问答都形成足够审计 RAG 质量的 Trace。
- `PRD-009`：知识更新失败不得破坏当前可用问答。
- `PRD-010`：核心推理不依赖收费云 API，手机承担模型算力。

## 3. 产品价值

站点既是 ProFlow 的项目说明书，也是 RAG 能力作品：用户不仅看到“答案”，还看到回答来自哪些源码/测试/文档；维护者还能复盘一次回答为什么成功或失败。

## 4. V0 完成定义

V0 不是“接口返回 200”。必须完成 Site → Dev Tunnel → Mac API → PostgreSQL/pgvector → iPhone 模型的真实闭环，拥有可重建知识快照、Hybrid + RRF + Reranker、Grounded Answer、Source、Trace、反馈与 Eval。
