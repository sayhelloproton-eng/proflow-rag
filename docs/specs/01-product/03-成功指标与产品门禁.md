# 成功指标与产品门禁

状态：REVIEWED_V0_2026-09-03

## 1. 质量

必须能回答代表性 ProFlow 事实问题，并在 exact engineering terms、自然语言、源码、测试证据四类查询上达到可接受 Recall。具体阈值由第一版 benchmark 建立后冻结，不在实现前伪造数字。

## 2. Grounding

正式答案的 ProFlow 事实必须能落到选中 Evidence；Source 绑定 `commit_sha + path + line range`。No-evidence 问题宁可明确“不足以回答”，不能用模型常识冒充项目事实。

## 3. 性能

TTFT、Retrieval、Rerank、Generation、Total latency 必须可测。具体预算在真实 iPhone + Mac 链路基准完成后冻结。

## 4. 稳定性

候选 Snapshot 构建失败、Reranker 超时、手机暂时不可用、Evaluation 写入失败等路径必须有明确降级或错误，不允许静默产生错误事实。

## 5. 产品体验

公开 Site 可访问；Streaming 连续；Sources 可打开；匿名会话可连续追问；反馈最小化；错误提示可理解。
